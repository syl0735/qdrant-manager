# Contributing

Thank you for contributing.

## Development

```bash
npm ci
npm run dev
```

Before opening a pull request, run:

```bash
npm run build
```

## Pull requests

- Keep each pull request focused on one change.
- Describe the user-visible behavior and how you verified it.
- Never commit API keys, snapshots, production endpoints, or other sensitive data.
- For destructive cluster operations, include the expected safety behavior in the pull request description.
